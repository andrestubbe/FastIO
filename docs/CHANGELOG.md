# FastIO Changelog

## [0.1.1] - 2026-08-14
- Integrated native `FastSIMD` (v0.1.3) AVX2 vector text scanner into C++ native engine.
- Created official JMH benchmark suite measuring 6,048 unbuffered native read ops/sec (~1.8 GB/s).
- Restructured `README.md` with Quick Start above Table of Contents, `Key Features`, `Real-World Use Cases`, `Performance Benchmarks`, and full `API Reference`.
- Updated full 5-module installation stack (`FastIO`, `FastSIMD`, `FastMemory`, `FastPointer`, `FastCore`).

## [0.1.0] - 2026-05-18
- Initial release of FastIO with native Windows unbuffered I/O and memory-mapped file channels.
