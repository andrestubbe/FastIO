# FastIO Changelog

## [0.1.1] - 2026-08-14
- Integrated native `FastSIMD` (v0.1.3) AVX2 vector engine for text scanning and tokenization.
- Added official JMH benchmark suite measuring 1.8 GB/s sequential unbuffered read throughput.
- Moved extensive API Reference details to `docs/REFERENCE.md` and added `API Quick Reference` section.
- Added `Key Features` and `Real-World Use Cases` documentation sections.
- Updated full 5-module dependency stack (`FastIO`, `FastSIMD`, `FastMemory`, `FastPointer`, `FastCore`).

## [0.1.0] - 2026-06-14
- Initial release of FastIO with native Windows unbuffered I/O and memory mapping.
