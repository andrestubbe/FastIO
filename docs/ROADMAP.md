# FastIO Roadmap

- [x] **v0.1.0** — Initial release with native Windows unbuffered I/O and memory mapping.
- [x] **v0.1.1** — Integrated `FastSIMD` AVX2 vector acceleration engine for text and CSV scanning.
- [ ] **v0.2.0** — Linux `io_uring` and macOS `kqueue` native engine backends.
- [ ] **v0.3.0** — Asynchronous direct I/O completion port (IOCP) event loops.
